# EV-Freight-Analytics

An interactive data analytics and visualization project.

The project analyses three different datasets:

1. EV Charging Infrastructure
2. Vehicle Health & Predictive Maintenance
3. Freight Transportation

## Technologies

- Python
- Pandas
- NumPy
- Google Colab
- Tableau

## Project Workflow

Data Collection --> Data Inspection --> Data Preprocessing -->
Exploratory Data Analysis --> Feature Engineering --> Tableau Visualization --> Interactive Dashboard -->
Result Analysis

## Dashboards

### 1. EV Charging Infrastructure Anlaysis of:
- Charging Stations
- Operational Status
- Connectors
- Operators
- Countries
- Geographical Distribution

### 2. Vehicle Health & Predictive Maintenance Analysis of:
- State of Charge (SoC)
- State of Health (SoH)
- Component Health
- Remaining Useful Life (RUL)
- Driving Conditions
- Maintenance Types

### 3. Freight Flow & Commodity Analysis of:
- Freight Volume
- Freight Value
- Commodities
- Trade Types
- Ton-miles
- Freight trends
